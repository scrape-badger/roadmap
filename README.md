# ScrapeBadger Roadmap

What we're building, and what we're fixing — in public.

Issues here are raised from real customer support tickets. Each one is either a
**feature** we've agreed to build or a **bug** we've confirmed and are fixing.
Customer names, emails, account details and API keys are never published here.

## How to read the board

| Label | Meaning |
|---|---|
| `feature` | A capability we plan to add |
| `bug` | Confirmed defect we're fixing |
| `api` | Affects the public `/v1/*` API surface |
| `planned` | Accepted, not started |
| `in-progress` | Being worked on now |
| `shipped` | Live in production |

## Want something on here?

- **Customers:** open a support ticket from your [dashboard](https://scrapebadger.com/dashboard/support)
  or ask BadgerBot in the portal chat. If it turns into roadmap work, we file it here and link it back.
- **Everyone else:** open an issue. Include what you're trying to do, not just what you want changed.

Support requests should go to the dashboard, not here — this repo is the roadmap,
not the support queue.
